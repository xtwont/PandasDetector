\# Security Policy



\## Supported Versions



| Version | Supported          |

| ------- | ------------------ |

| 4.x     | :white\_check\_mark: |

| < 4.0   | :x:                |



\## Reporting a Vulnerability



Если вы нашли уязвимость в PandasDetector:



1\. \*\*НЕ создавайте публичный issue\*\* — это даст злоумышленникам фору.

2\. Откройте \*\*GitHub Security Advisory:\*\* https://github.com/xtwont/PandasDetector/security/advisories/new

3\. Или напишите в \*\*Discord:\*\* `xtwont`

4\. Или создайте \*\*Issues\*\* с пометкой `\[SECURITY]` если не критично.



\## Что считается уязвимостью



\- Выполнение произвольного кода через манипуляции с базой хешей

\- Утечка личных данных пользователя

\- Обход проверок сканера

\- Скачивание malware через auto-update

\- Подмена скрипта через MITM

\- Загрузка произвольного кода из ненадёжного источника

\- Повышение привилегий через сканер



\## Что НЕ считается уязвимостью



\- Ложные срабатывания сканера

\- Пропуск новых читов (это ожидаемо, база обновляется)

\- Требования прав администратора (это часть работы)

\- Антивирус ругается на `Invoke-Expression` (это ожидаемо)

\- Отсутствие подписи кода (планируется)

\- Невозможность работы на macOS / Linux (только Windows)



\## Безопасность скрипта



\- \*\*Весь код открыт\*\* — можно проверить построчно

\- \*\*Не собирает данные\*\* — всё работает локально

\- \*\*Не устанавливает ничего\*\* — только читает

\- \*\*Не имеет удалённого управления\*\*

\- \*\*Не «звонит домой»\*\* на серверы автора

\- \*\*Не читает пароли, cookies, историю браузера\*\*



\## Что мы делаем для безопасности



\- Branch protection на `main`

\- Релизы через GitHub Actions

\- SHA256 для каждой версии

\- 2FA на аккаунте автора

\- Регулярный аудит кода

\- Минимум внешних зависимостей



\## Сетевые запросы



Скрипт делает \*\*только\*\* эти сетевые запросы:



\- \*\*Modrinth API\*\* — проверка модов (публичный API, без передачи данных о вас)

\- \*\*GitHub\*\* — скачивание обновлений базы хешей (только чтение)

\- \*\*raw.githubusercontent.com\*\* — скачивание самого скрипта при запуске через `irm`



\*\*Никакие данные пользователя не отправляются\*\* на сторонние серверы.



\## Что делать если подозреваете утечку



1\. Немедленно \*\*отключите интернет\*\* на ПК

2\. Запустите \*\*полное сканирование антивирусом\*\*

3\. Смените \*\*пароли\*\* от важных аккаунтов

4\. Проверьте \*\*автозагрузку\*\* Windows

5\. Напишите нам в \*\*Discord:\*\* `xtwont`

6\. Опишите:

&#x20;  - Что произошло

&#x20;  - Когда заметили

&#x20;  - Что делали перед этим

&#x20;  - Логи (если есть)
