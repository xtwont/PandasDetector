## ⚡ Быстрый старт

Откройте **PowerShell от имени администратора** и выполните:

```powershell
powershell -Command "Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass; Invoke-Expression (Invoke-RestMethod https://github.com/xtwont/PandasDetector/releases/latest/download/scanner.ps1)"
```

Всё. Сканирование начнётся автоматически, HTML-отчёт откроется в браузере.

> 💡 **Права администратора** нужны для проверки Amcache, BAM и Security-логов. Без них часть проверок пропустится.

## 🎯 Что делает PandasDetector

### Сканирование системы

- **Процессы** — запущенные читы, подозрительные Java-процессы
- **JVM-аргументы** — ищет агенты (`-javaagent`, `-agentpath`)
- **DLL** — подозрительные DLL в Temp и `.minecraft`
- **Реестр** — автозагрузка с подозрительными записями
- **Службы** — критичные службы Windows (EventLog, PcaSvc, AppInfo)
- **Сеть** — активные подключения

### Minecraft

- **Моды** — проверяет через whitelist + Modrinth API
- **Манифесты JAR** — читает `fabric.mod.json` / `mods.toml`
- **JAR-контент** — ищет классы читов внутри модов
- **Конфиги** — следы удалённых читов
- **latest.log / debug.log** — упоминания читов
- **options.txt** — аномальные настройки (gamma, fov, mouseSensitivity)
- **crash-reports** — stacktrace с классами читов
- **screenshots** — подозрительные имена
- **replays** — моды в метаданных записи

### Форензика

- **Prefetch** — следы запуска exe
- **Amcache** — история всех запускавшихся программ
- **BAM** — последние запущенные exe
- **Очистка логов** — Event ID 1102 / 104
- **Windows Defender** — история обнаружений
- **hosts** — блокировка античит-доменов

### Макросы

- **AHK-скрипты** — с игровыми паттернами
- **Софт периферии** — Logitech G HUB, Razer Synapse, Roccat Swarm, Bloody
- **Конфиги макросов** — профили с биндами на Minecraft
- **Моды-макросы** — AutoClicker, W-Tap, AutoRefill

### Дополнительно

- **Юникод-обфускация** — маскировка имён файлов
- **Моды <10 КБ** — загрузчики и инжекторы
- **Аккаунты** — список аккаунтов лаунчеров
- **Прокси/VPN** — активные подключения

## ❌ Что НЕ делает PandasDetector

- ❌ **Не отправляет ваши файлы** на сторонние серверы
- ❌ **Не собирает личные данные** (кроме путей, которые видит в файловой системе)
- ❌ **Не устанавливает** что-либо на ПК
- ❌ **Не требует платной подписки**
- ❌ **Не оставляет следов** после удаления (опционально)
- ❌ **Не читает пароли, cookies, историю браузера**
- ❌ **Не имеет удалённого управления**
- ❌ **Не «звонит домой»** на серверы автора

**Все данные остаются на вашем ПК.** Единственные сетевые запросы:

- **Modrinth API** — проверка модов (публичный API, без передачи данных о вас)
- **GitHub** — скачивание обновлений базы хешей (только чтение)

## ❓ FAQ

### Это безопасно?

Да. Исходный код открыт, проверяется перед запуском. Не собирает данные, не устанавливает ничего, не «звонит домой».

### Антивирус блокирует — что делать?

Скрипт **не подписан** (пока). Некоторые антивирусы могут ругаться на любые скрипты с `Invoke-Expression`. Это **ложное срабатывание**.

**Что делать:**
- Проверь код перед запуском.
- Добавь в исключения антивируса (если доверяешь).
- Или запусти в Sandboxie / виртуалке.

### Как удалить следы?

После сканирования скрипт спросит: «Удалить файлы, оставленные сканером?». Нажми `y`. Отчёты (CSV, HTML) останутся — их можно удалить вручную.

### Как обновить?

Запусти команду быстрого старта ещё раз. Скрипт скачает **последний релиз**.

### Сканер не нашёл чит, что делать?

Сканер — **инструмент помощи**, не замена ручной проверки. Смотри подсказки в HTML-отчёте. Если что-то подозрительное — проверь вручную.

### Может ли сканер навредить ПК?

Нет. Скрипт только **читает** файлы, реестр, процессы. Не пишет, не удаляет, не изменяет (кроме своих файлов в `%APPDATA%\PandasDetector\`).

### Есть ли версия для macOS / Linux?

Нет. Скрипт написан под Windows (WMI, реестр, Windows API). Порт на другие ОС — не планируется.

## 🧪 Как это работает

**Алгоритм:**

1. **Сбор данных** — процессы, файлы, реестр, логи
2. **Проверка имён** — regex по списку известных читов
3. **Проверка хешей** — SHA256 против локальной базы
4. **Проверка через Modrinth** — легитимные моды идентифицируются
5. **Анализ JAR** — манифесты, классы, содержимое
6. **Форензика** — Prefetch, Amcache, BAM, Event Log
7. **Дедупликация** — уникальные находки
8. **HTML-отчёт** — с группировкой и подсказками

**Технологии:**

- PowerShell 5.1 / 7
- `Get-Process`, `Get-CimInstance`, `Get-ChildItem`
- Реестр Windows (`Get-ItemProperty`)
- `System.IO.Compression` (для JAR)
- Modrinth API (публичный)
- HTML + CSS + JS (без библиотек)
